量化技术派（技术分析量化策略）中，股票买入区间、卖出价位、止损位的原则主要是基于“价格行为包含一切信息”、趋势跟随/均值回归、历史会重演等技术分析核心假设，通过可量化的规则（如指标阈值、形态突破）来制定系统化买卖逻辑。 
这些原则强调客观、可回测、风险优先，避免主观情绪。以下是常见原则总结：
1. 买入区间（Entry Rules）的原则
买入不是随意低吸，而是等待高概率信号确认趋势启动或反转，结合支撑位/超卖区。
•  支撑位/区间交易：在历史支撑位（前低、均线支撑、Fibonacci回撤位）附近买入。区间震荡市中，在下轨/支撑买入，预期反弹至中轨或上轨。 
•  趋势跟随：价格突破关键阻力（如前高、均线）+ 成交量放大时买入（右侧交易，避免左侧抄底）。
•  常用指标量化规则：
	•  移动平均线 (MA/EMA)：短期均线（如5/10日）上穿长期均线（金叉）买入。
	•  布林带 (Bollinger Bands)：价格触及或跌破下轨 + RSI < 30（超卖）时买入，预期回归中轨。 
	•  RSI：低于30（超卖区）反弹时买入，避免单独使用（假信号多）。
	•  MACD：柱状图由负转正、DIFF上穿DEA（金叉）买入。
•  量化原则：多指标共振（至少2-3个确认）、成交量验证、避免高位追涨。买入区间往往设置在某一价格带（如支撑±一定ATR波动范围），而非精确单点。
2. 卖出价位（Exit/Target）的原则
卖出分为止盈（获利了结）和趋势结束信号，核心是“让利润奔跑，但不贪婪”。
•  阻力位/超买区：接近历史阻力、上轨、Fibonacci扩展位时卖出。
•  指标信号：
	•  布林带：触及或突破上轨 + RSI > 70（超买）卖出。
	•  MA：短期均线下穿长期均线（死叉）卖出。
	•  MACD：死叉或柱状图收窄卖出。
•  止盈方法（量化常见）：
	•  固定比例：盈利达到10-20%（或根据回测优化）卖出。
	•  追踪止盈：用Trailing Stop，随价格上涨上移止盈位（如ATR倍数或新高回撤一定比例）。
	•  均值回归：价格回归布林中轨或目标价位卖出。
	•  时间止盈：持有超过设定天数强制卖出（防止持仓过久）。 
3. 止损位（Stop-Loss）的原则
止损是量化策略的核心风控，优先于盈利。原则是“小亏快止，大赚慢走”，保护资本。
•  核心原则：
	•  合理性：基于波动率设置，不能太紧（频繁止损）或太松（大亏）。常用ATR (Average True Range) 的1-3倍作为距离。 
	•  技术位：放在近期低点/支撑下方、均线下方、或波动区间外，避免被正常噪音扫掉。
	•  固定百分比：常见5-10%（根据个股波动性调整，高波动股可放宽）。
	•  灵活/动态：趋势中用追踪止损（Trailing Stop），盈利后上移止损位锁定利润。
•  常见方法：
	•  价格止损：跌破买入价一定比例。
	•  指标止损：跌破关键均线或布林下轨。
	•  时间止损：持有超期未盈利即止损。 
风险控制总体原则：单笔风险控制在总资金的1-2%以内（仓位大小 = 总资金 × 风险承受 / 止损距离）。多元化、多因子共振、严格回测避免过拟合。 
量化技术策略的整体框架特点
•  系统化：所有规则写成代码，可回测历史数据优化参数（MA周期、RSI阈值等）。
•  分类：趋势跟随（MA/MACD突破）、均值回归（Bollinger + RSI）、突破策略等。
•  注意事项：
	•  震荡市易假突破（多止损），趋势市效果好。
	•  结合成交量、波动率，避免单一指标。
	•  持续优化，但防止曲线拟合；实盘需考虑滑点、手续费。
	•  止损优先：许多量化策略胜率<50%，靠盈亏比取胜。
例子（简单MA + Bollinger策略）：
•  买入：5日MA上穿20日MA + 价格近下轨 + RSI<35。
•  卖出：5日MA死叉 或 价格达上轨 + RSI>65。
•  止损：买入价下方 2×ATR 或 最近低点下方。



量化技术派的核心原则可以归纳为以下几条：                                              
                                                                                        
  ---                                                                                   
  1. 趋势是唯一的朋友                                                                   
                                                                                        
  核心： 价格以趋势方式演变，顺势而为是盈利的根本。                                     
                                                                                        
  ┌──────────────────────────────────────┬───────────────────┐                          
  │                 工具                 │       作用        │                          
  ├──────────────────────────────────────┼───────────────────┤                          
  │ 均线排列（MA5 > MA10 > MA20 > MA60） │ 确认趋势方向      │                          
  ├──────────────────────────────────────┼───────────────────┤                          
  │ 价格 vs MA20 的偏离度                │ 判断是否过热/过冷 │                          
  ├──────────────────────────────────────┼───────────────────┤                          
  │ MA20 上翘/走平/下弯                  │ 判断趋势强度      │                          
  └──────────────────────────────────────┴───────────────────┘                          
                                                                                        
  只参与上升趋势的股票，下降趋势一律回避——这是铁律。                                    
                                                                                        
  ---                                                                                   
  2. 支撑与压力决定盈亏比                                                               
                                                                                        
  核心： 在支撑位买，在压力位卖，盈亏比 > 3:1 才值得参与。                              
                                                                                        
  买入价 100，止损 95（亏5%），第一目标 120（赚20%）                                    
  → 盈亏比 = 20% / 5% = 4 : 1 ✓                                                         
                                                                                        
  - 支撑失效（跌破止损）→ 必须卖出，这是纪律                                            
  - 压力突破 → 压力变支撑，可以加仓或上调止损                                           
                                                                                        
  ---                                                                                   
  3. 量价关系确认有效性                                                                 
                                                                                        
  核心： 没有成交量配合的价格信号不可信。                                               
                                                                                        
  ┌────────────┬──────────────────────┐                                                 
  │    信号    │     需要配合的量     │                                                 
  ├────────────┼──────────────────────┤                                                 
  │ 突破压力位 │ 放量（>1.5倍均量）   │                                                 
  ├────────────┼──────────────────────┤                                                 
  │ 回调到支撑 │ 缩量（<均量）        │                                                 
  ├────────────┼──────────────────────┤                                                 
  │ 顶部背离   │ 价创新高，量没创新高 │                                                 
  └────────────┴──────────────────────┘                                                 
                                                                                        
  当前策略中 vol_ratio 就是用来做这个过滤的。                                           
                                                                                        
  ---                                                                                   
  4. 多策略共振提高胜率                                                                 
                                                                                        
  核心： 单一指标胜率不高（~55%），多个独立策略同时选出同一只股票时胜率显著提升。       
                                                                                        
  - MaVolume（均线金叉 + 放量）— 捕捉趋势启动                                           
  - TurtleTrade（新高突破）— 捕捉加速段                                                 
  - 交集 = 共振，这也是为什么系统要取两个策略的合集                                     
                                                                                        
  ---                                                                                   
  5. 截断亏损，让利润奔跑                                                               
                                                                                        
  核心： 决定盈利的不是胜率，而是盈亏比。                                               
                                                                                        
  ┌──────────┬───────────┬─────────────────────┐                                        
  │   亏损   │   盈利    │      胜率要求       │                                        
  ├──────────┼───────────┼─────────────────────┤                                        
  │ -5% 止损 │ +10% 止盈 │ 只需 34% 胜率就保本 │                                        
  ├──────────┼───────────┼─────────────────────┤                                        
  │ -5% 止损 │ +20% 止盈 │ 只需 20% 胜率就赚钱 │                                        
  └──────────┴───────────┴─────────────────────┘                                        
                                                                                        
  当前系统的止损设置在最近支撑下方 3%，目标取下一个压力位，天然实现了盈亏比 > 2:1。     
                                                                                        
  ---                                                                                   
  6. 数据必须标准化                                                                     
                                                                                        
  核心： 只有使用统一复权方式的数据，技术指标才有意义。                                 
                                                                                        
  - 使用 前复权（adjustflag=2）                                                         
  - 所有计算基于同一套数据                                                              
  - 与主流平台（同花顺、雪球）保持一致                                                  
                                                                                        
  ---                                                                                   
  这套体系核心一句话：顺趋势、找共振、算盈亏、守纪律。系统现在做的就是把这些规则自动化，
  每天 21 点输出结果。
