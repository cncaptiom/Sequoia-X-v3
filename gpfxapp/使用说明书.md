## 1. 应用概述

本应用是一款面向A股市场的量化分析工具，提供实时行情、技术分析、买卖评级、策略配置等功能。

**核心技术特性：**
- 基于7大策略的量化打分体系（MaVolume、TurtleTrade、均值回归、量价关系、ATR通道突破、MACD+RSI共振、MA20/60金叉死叉）
- 趋势过滤机制 — 只参与上升趋势，下降趋势一律回避
- 动态权重分配 — 根据启用的策略自动归一化权重
- 盈亏比计算 — 自动寻找支撑位和压力位，计算风险收益比
- 精选推荐 — 从涨幅榜和成交额榜中自动筛选优质股票

**配色说明（中国股市标准）：**
- 红色 `#FF4444` = 上涨
- 绿色 `#00C853` = 下跌
- 天空蓝主题背景

## 2. 快速开始

### 2.1 底部导航栏

应用底部有5个导航标签，从左到右依次是：

| 图标 | 标签 | 功能 |
|------|------|------|
| 房子 | **首页** | 大盘指数 + 自选股列表 |
| 搜索 | **搜索** | 股票搜索 + 排行榜 + 板块 + 精选推荐 |
| 图表 | **详情** | 个股行情 + K线图 + 技术分析 |
| 调节 | **策略** | 7大量化策略参数配置 |
| 齿轮 | **设置** | 通知开关、关于信息 |

### 2.2 添加自选股

1. 进入「发现股票」页面
2. 在顶部搜索框输入股票代码或名称（如 `600519` 或 `贵州茅台`）
3. 在搜索结果中点击右侧的星标 `☆` 按钮，变为实心星 `★` 即添加成功
4. 也可在排行榜、板块成分股、精选推荐中点击股票进入详情页，在详情页顶部点击星标添加

### 2.3 删除自选股

- **首页方式：** 在自选股列表中，点击股票卡片右侧的 `✕` 按钮，弹出确认对话框后点击「删除」
- **详情页方式：** 进入股票详情页，点击已实心的星标 `★` 即可取消关注

## 4. 发现股票 — 搜索与排行

### 4.1 股票搜索

- 顶部搜索框支持按**股票代码**或**中文名称**模糊搜索
- 搜索结果列表展示：股票名称、代码、所属交易所
- 每项右侧星标可快速添加/取消自选
- 点击搜索结果进入股票详情页

### 4.2 精选推荐

自动从涨幅榜（前30支）和成交额榜（前10支）中合并去重，提取40支候选股票，通过分析引擎进行技术分析，筛选出优质标的。

**筛选机制（三级优选）：**

| 优先级 | 条件 | 数量 |
|--------|------|------|
| 第一优先 | 评级为「强烈买入」或「买入」 | 取前10支 |
| 第二优先 | 趋势通过 + 评分 ≥ 2 | 取前5支 |
| 第三优先 | 评分最高的潜力股 | 取前3支 |

精选推荐以水平滑动的卡片列表展示，每张卡片显示：
- 股票名称
- 评级标签（「强烈买入/买入/潜力」）
- 涨跌幅

点击任意卡片进入该股票详情页。

### 4.3 市场排行

三个排行榜通过Tab切换：

| Tab | 排序依据 | 数据来源 |
|-----|----------|----------|
| **涨幅榜** | 涨跌幅从高到低 | 新浪财经排名API |
| **跌幅榜** | 涨跌幅从低到高 | 新浪财经排名API |
| **成交额榜** | 成交额从高到低 | 新浪财经排名API |

每个排行榜显示前10名，每项包含：排名序号、股票名称代码、当前价、涨跌幅色块。

### 4.4 热门板块

以3列网格展示行业板块（最多12个），每项显示：
- 板块名称
- 涨跌幅（红色/绿色）

> **注意：** 当网络环境无法访问东方财富板块API时，将使用静态备选板块列表，此时涨跌幅可能显示为0.00%。

**查看板块成分股：** 点击板块卡片，底部弹出成分股列表（可拖拽展开），显示该板块内个股的排名，点击任意股票进入详情页。

显示分析引擎对该股票的综合评定：

- **评级星标：** ★★★★★ ~ ★（对应强烈买入到回避）
- **评级标签：** 强烈买入 / 买入 / 观望 / 关注 / 回避

使用 fl_chart 绘制，默认显示最近60根K线的走势：

- **主图区域（上）：** 收盘价连线图

  - 下方浅色填充区域
  - X轴显示日期，Y轴显示价格
- **成交量图（下）：** 红色柱（涨）/ 绿色柱（跌），反映成交量相对大小
- **技术指标切换（底部）：** MA / BOLL / RSI 标签按钮（当前仅有MA已实现，其余为预留）

### 5.5 技术分析详情

展示7大策略的详细评分结果：

- **策略得分条：** 每个策略以进度条+分数显示（绿色为正分，红色为负分）
  - MaVolume（均线放量）
  - TurtleTrade（突破）
  - 均值回归
  - 量价关系
  - ATR通道突破
  - MACD+RSI共振
  - MA20/60金叉死叉
- **趋势判断：** 均线排列状态详细说明
- **盈亏比：** 精确数值
- **止损位 / 止盈位：** 具体价格
- **买入区间：** 当现价接近支撑位时显示（如 `168.50 - 171.87`）

**信号明细列表：** 每条信号包含：
- 方向图标（↑看多 / ↓看空 / —中性）
- 信号名称（如"MaVolume-金叉放量"）

## 6. 策略配置 — 量化分析引擎

策略页面是应用的核心，所有7大策略均可独立开关和调整参数。启用的策略会参与动态权重分配。

### 6.1 策略总览

| # | 策略名称 | 默认权重 | 适用场景 |
|---|----------|----------|----------|
| A | **MaVolume** 均线金叉放量 | 28% | 趋势跟踪 + 量能确认 |
| B | **TurtleTrade** 趋势突破 | 23% | 突破交易，捕捉主升浪 |
| C | **均值回归** 超卖反转 | 16% | 震荡行情，反向交易 |
| D | **量价关系** 确认信号 | 11% | 辅助验证信号有效性 |
| E | **ATR通道突破** 进攻型 | 22% | 基于波动率的趋势跟踪 |
| F | **MACD+RSI共振** 顺势确认 | 动态 | MACD金叉死叉+RSI超买超卖 |
| G | **MA20/60金叉死叉** 趋势判断 | 动态 | 中长期趋势判定 |

> **动态权重说明：** 启用策略总数不同时，权重会自动归一化，总和始终为100%。例如只启用3个策略时，它们的权重会重新按比例分配。

### 6.2 策略A: MaVolume

默认短期均线5日，长期均线20日，放量阈值1.5倍。

| 参数 | 范围 | 说明 |
|------|------|------|
| 短期均线周期 | 3~20 | MA短线参数 |
| 长期均线周期 | 10~60 | MA长线参数 |
| 放量阈值 | 1.0~3.0倍 | 成交量超过均量的倍数判定放量 |

评分逻辑：
- 金叉 + 放量 → +3分
- 金叉 + 量能不足 → +1分
- 死叉 → -3分
- 多头排列 → +2分
- 价格在MA20上方 → +1分

### 6.3 策略B: TurtleTrade

默认突破周期20日，中期新高周期60日。

| 参数 | 范围 | 说明 |
|------|------|------|
| 突破周期 | 10~60日 | 计算近期高/低点的窗口 |
| 中期新高周期 | 30~120日 | 中期新高判定周期 |

评分逻辑：
- 突破前高 + 放量 → +3分
- 跌破前低 → -3分
- 创60日新高 → +2分

### 6.4 策略C: 均值回归

默认RSI周期14，超买阈值70，超卖阈值30。

| 参数 | 范围 | 说明 |
|------|------|------|
| RSI周期 | 6~30 | RSI计算周期 |
| 超买阈值 | 60~90 | 超过此值视为超买 |
| 超卖阈值 | 10~40 | 低于此值视为超卖 |

评分逻辑：
- 触及下轨 + RSI超卖 → +3分（反弹信号）
- 触及上轨 + RSI超买 → -2分（回调风险）
- RSI底背离 → +3分
- RSI顶背离 → -3分

### 6.5 策略D: 量价关系

| 参数 | 范围 | 说明 |
|------|------|------|
| 放量异常阈值 | 2.0~5.0倍 | 超过此值视为异常放量 |

评分逻辑：
- 放量上涨 → +2分
- 缩量回调 → +1分
- 价创新高量没创新高 → -2分（背离）
- 异常放量 → -1分（警惕派发）

### 6.6 策略E: ATR通道突破（进攻型）

| 参数 | 范围 | 说明 |
|------|------|------|
| 趋势周期 | 10~60日 | EMA+ATR计算周期 |
| 通道窗口 | 10~50日 | 通道计算窗口 |
| 出场阈值 | 0.1~1.0 | 趋势动能减弱判定 |
| ATR止损倍数 | 1.0~4.0x | 止损位计算倍数 |

评分逻辑：
- 多头趋势 + 突破通道上轨 → +3分
- 多头趋势但未突破 → +1分
- 空头趋势 + 跌破下轨 → -3分
- 趋势过热（评分>3）→ -1分
- 趋势动能衰减 → -2分

### 6.7 策略F: MACD+RSI共振

无额外参数，默认使用MACD(12,26,9) + RSI(14)。

评分逻辑：
- MACD金叉 + RSI健康 + 放量 → +3分
- MACD金叉 → +2分
- MACD死叉 → -3分
- RSI超卖 + MACD绿柱缩短 → +2分
- RSI超买 + MACD红柱缩短 → -2分
- DIF在零轴上方 → +1分（多头市场）

### 6.8 策略G: MA20/60金叉死叉

需要至少61根K线数据才能计算。

评分逻辑：
- MA20上穿MA60（金叉）→ +3分
- MA20下穿MA60（死叉）→ -3分
- 价格在MA20和MA60之上 → +1分
- MA60方向向上 → +1分
- MA20在MA60之上 → +1分

### 6.9 趋势过滤开关

- **启用趋势过滤**（默认开启）：只分析上升趋势股票
- 趋势过滤条件（三项全满足才算通过）：
  1. 均线多头排列：MA5 > MA10 > MA20 > MA60
  2. MA20方向向上（上翘）
  3. 收盘价在MA20上方

### 6.10 恢复默认设置

页面底部有「恢复默认设置」按钮，点击可将所有策略参数重置为出厂默认值。

## 7. 设置 — 通知与关于

### 7.1 通知设置

7个通知开关，全部默认开启：

| 通知类型 | 推送时机 |
|----------|----------|
| **启用通知** | 总开关，关闭后不推送任何通知 |
| **金叉/死叉通知** | 均线金叉死叉信号出现时 |
| **超买/超卖通知** | RSI超买超卖信号出现时 |
| **突破通知** | 价格突破关键位时 |
| **买入区间通知** | 价格进入买入区间时提醒 |
| **止损通知** | 价格触及止损位时提醒 |
| **止盈通知** | 价格触及止盈位时提醒 |

通知仅在**重点关注**的股票上生效，且仅限**交易时段**（周一至周五 9:30-11:30, 13:00-15:00）。

**防重复机制：** 同一信号的相同通知不会反复推送。当价格离开触发区域后，可再次触发。

**测试通知：** 页面底部有「发送测试通知」按钮，可验证通知功能是否正常。

### 7.2 刷新设置

- **重点关注股票刷新间隔：** 15秒自动刷新一次（仅交易时段生效）

### 7.3 关于

- **版本号：** v1.1.0

## 8. 评级体系说明

### 8.1 评级分类

| 评级 | 星级 | 条件 | 建议 |
|------|------|------|------|
| **强烈买入** | ★★★★★ | 趋势通过 + 总分 ≥ 6 + 盈亏比 > 3 | 可重仓 |
| **买入** | ★★★★ | 趋势通过 + 总分 ≥ 4 + 盈亏比 > 2 | 可建仓 |
| **观望** | ★★★ | 趋势通过 + 总分 ≥ 2 | 持有观察 |
| **关注** | ★★ | 趋势通过 + 总分 < 2 | 等待更好时机 |
| **回避** | ★ | 趋势未通过 | 下降趋势不参与 |

### 8.2 标签含义

在自选股列表中，右侧色块标签的含义：

| 标签 | 对应评级 | 颜色 |
|------|----------|------|
| **买入** | 强烈买入 或 买入 | 红色 |
| **持有** | 观望 | 橙色 |
| **关注** | 关注 | 蓝色 |
| **回避** | 回避 | 绿色 |

在自选股名称旁，当开启重点关注的股票出现买入信号时，会出现红色「买」徽标；出现卖出/回避信号时，会出现绿色「卖」徽标。

### 8.3 评分构成

总分由7大策略的加权得分累加而成，每个策略的权重根据启用策略总数动态归一化，确保总分始终在合理范围内。

**综合评级阈值：**
- 总分 ≥ 6 → 可冲击强烈买入（还需盈亏比>3）
- 总分 ≥ 4 → 可评定买入（还需盈亏比>2）
- 总分 ≥ 2 → 观望
- 总分 < 2 → 关注

## 9. 数据来源与免责

### 9.1 数据源

| 数据类型 | 主数据源 | 备选数据源 |
|----------|----------|------------|
| 实时行情 | 腾讯行情API (`qt.gtimg.cn`) | 东方财富API |
| K线数据 | 东方财富K线API | 新浪财经K线API |
| 股票搜索 | 东方财富搜索API | 代码直查 |
| 排行榜 | 新浪财经排名API | — |
| 行业板块 | 东方财富板块API | 静态备份数据 |
| 大盘指数 | 腾讯行情API（批量） | 逐个股查询 |

### 9.2 数据延迟说明

- 实时行情数据为**准实时**，可能存在数秒到数十秒的延迟
- K线数据在盘后更新，盘中数据为实时生成
